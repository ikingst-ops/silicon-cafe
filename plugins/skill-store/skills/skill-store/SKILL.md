# 1VR Skill Store 桥接

按用户任务搜索 1VR Skill Store（https://1vr.com）中已体检的技能，并给出一句话安装指引。

## 怎么做

1. 先确认用户要完成的任务和关键词，再到 1VR Skill Store 的公开技能目录（https://1vr.com/skills）或其公开 API（https://1vr.com）按关键词搜索。
2. 只报告搜索到的技能：名称、一句话说明、一句话安装指引。
3. 找不到匹配技能时，直接说明未找到，不要编造技能名称、地址或安装命令。

## 如实描述

- 数据来自 https://1vr.com 的公开 API 与公开技能目录，数量口径为 2,949 条已体检技能。
- 不承诺任何技能安全、可用或与用户环境兼容；安装前请用户自行检查技能来源与内容。
- 不要把“已体检”等同于“安全”。
